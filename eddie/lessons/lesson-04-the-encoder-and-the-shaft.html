Lesson 04
The Encoder and the Shaft

TASK — Count clicks of a knob, up and down, 20 to a turn. Then make a stepper motor follow that knob exactly — one turn of the knob, one turn of the shaft.
CONDITIONS — Bench 12 V supply. Pico, rotary encoder module, stepper + driver from Lesson 02, Thonny, AI tutor.
STANDARD — The count tracks the knob both directions and never drifts. The shaft mirrors the knob 1:1. The serial print shows the number changing on every click.

The big idea: last lesson the knob told you where it was — "I'm at 60%." This knob is different. It doesn't know where it is. It only tells you "I just moved one click, this direction." That's an encoder. It reports change, not position. Which means somebody has to remember the running total — and that somebody is your code. The number doesn't live in the knob. It lives in a variable you keep.

⚠ Safety Brief

  • Still a 12 V bench. Friendly. The encoder itself runs on 3.3 V logic — no motor power near it.
  • The stepper rule from Lesson 02 still holds: never unplug the motor while the driver is powered. Power down first.
  • DIP switches on the driver: full step, 200 per revolution, same as Lesson 02. Current set to match the motor.
  • Wire with the 12 V off. Build it, look at it, power it.

The three stages of this lesson

  1. Count the knob. No motor. Just the encoder and a number that goes up and down as you turn.
  2. Do the gear math. The stepper turns in 200 steps. The knob turns in 20 clicks. Figure out how they connect.
  3. Make the shaft follow. Turn the knob, the motor turns with it. 1:1. The number is the truth they share.

Table I — Dry

Nothing powered. Read Stage 1's code and think before you touch it.

An encoder has two signal wires, CLK and DT. As you turn the knob, both send pulses — but one leads the other, and which one leads tells you the direction. Turn one way, CLK moves first. Turn the other way, DT moves first. That's the whole trick.

  1. If the code only watched CLK and ignored DT, what could it not tell you?
  2. The knob has bumps you can feel as you turn — detents. This one gives 20 per revolution. If you turn it exactly one full turn clockwise, what should the count read? One turn back?
  3. Why does the count have to live in a variable instead of being read off the knob like last lesson's pot?

# Stage 1: count the knob. Up when you turn one way,
# down the other. 20 clicks makes one full turn.
#
# The number lives HERE, in this variable. The knob doesn't
# remember anything - we do.

from machine import Pin
import time

clk = Pin(16, Pin.IN, Pin.PULL_UP)   # first signal wire
dt  = Pin(17, Pin.IN, Pin.PULL_UP)   # second signal wire

count = 0                    # our running total. starts at zero.

# Remember what CLK looked like last time we checked, so we can
# tell when it CHANGES. Change is the whole game here.
last_clk = clk.value()

print("Turn the knob. Count starts at 0.")

while True:
    now_clk = clk.value()            # what is CLK doing right now?

    # Did CLK just change from its last state? That's one step of turn.
    if now_clk != last_clk:

        # When CLK changes, look at DT. If DT is different from CLK,
        # we turned one way. If DT matches CLK, we turned the other.
        # (Which is which depends on your wiring - fix it in Live if
        #  it counts backwards.)
        if dt.value() != now_clk:
            count = count + 1        # one click clockwise
        else:
            count = count - 1        # one click counter-clockwise

        print("count:", count)       # show the number every change

    last_clk = now_clk               # remember for next time around
CHECKPOINT — Turn slowly. Each detent bumps the number by one. One full revolution should move it by about 20. Turn back and it returns. If it counts down when you turn clockwise, that's fine — you'll fix the direction in the Live table. If the number jumps by 2s or skips around, note it; that's real and we'll talk about it.

Stage 2 — The Gear Math (no new wiring)

Now think, before you wire the motor. You have two things that both "turn," but they count differently:

  • The encoder makes 20 clicks per revolution.
  • The stepper makes 200 steps per revolution (full-step, from the DIP switches — same as Lesson 02).

You want them to agree: one full turn of the knob = one full turn of the shaft. So each single click of the knob has to equal how many steps of the motor?

200 steps ÷ 20 clicks = 10 steps per click. That's the whole gear ratio, and it's just division. Every time the encoder count changes by 1, the motor needs to move 10 steps. Turn the knob one full revolution (20 clicks × 10) and the motor moves 200 steps — exactly one revolution. They're geared together through a number, not through gears.

Prove it to yourself with a pencil before you run any code: if you turn the knob 5 clicks, how many steps should the motor take? Half a turn of the knob? Write it down.

# Stage 3: the encoder drives the stepper. Turn the knob,
# the shaft follows. One turn of the knob = one turn of the shaft.

from machine import Pin
import time

# --- the encoder (from Stage 1) ---
clk = Pin(16, Pin.IN, Pin.PULL_UP)
dt  = Pin(17, Pin.IN, Pin.PULL_UP)

# --- the stepper driver (from Lesson 02) ---
# active low: resting HIGH, we pull LOW to fire a step.
step_pin = Pin(2, Pin.OUT, value=1)
dir_pin  = Pin(3, Pin.OUT, value=1)

STEPS_PER_CLICK = 10         # 200 motor steps / 20 knob clicks. The gear ratio.

count = 0                    # where the knob says we are
last_clk = clk.value()

def move_stepper(steps, direction):
    # Point the motor the right way, then fire that many steps.
    dir_pin.value(direction)
    for i in range(steps):
        step_pin.value(0)
        time.sleep_us(500)
        step_pin.value(1)
        time.sleep_us(500)

print("Turn the knob. The shaft follows. count = 0")

while True:
    now_clk = clk.value()

    if now_clk != last_clk:

        if dt.value() != now_clk:
            count = count + 1
            move_stepper(STEPS_PER_CLICK, 1)    # 10 steps, one direction
        else:
            count = count - 1
            move_stepper(STEPS_PER_CLICK, 0)    # 10 steps, the other way

        print("count:", count)                  # the shared truth

    last_clk = now_clk
CHECKPOINT — Turn the knob one click, the shaft jumps 10 steps. Turn a full revolution, the shaft turns a full revolution with it. Put a tape flag on the shaft and a mark on the knob — they should stay locked together. The number in the Shell matches both.

Live modifications — all of them, proven by the shaft:

  1. Fix the direction if it's backwards. If turning the knob clockwise spins the shaft the wrong way, make them agree. (Two ways to fix it — in the counting, or in the motor direction. Either is fine. Know which one you changed and why.)
  2. Change the gearing. Make one full turn of the knob equal two full turns of the shaft. What number did you change, and why that one?
  3. Home it. Add a rule: when the count comes back to 0, print "HOME" next to the number. Now the number means something — a position you can return to.
  4. Break the ratio on purpose. Set STEPS_PER_CLICK = 7. Turn one full knob revolution. Does the shaft land back where a full turn should? Explain what 7 did.
